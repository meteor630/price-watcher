# Статус функционала

Обновляется после каждой задачи. Одна строка на функцию. Статусы: реализовано / частично / не реализовано / отложено.

## Основа

- Карта проекта и проверка границ модулей — реализовано
- Конфигурация, логи, типизированные ошибки — реализовано
- Схема базы и миграции — частично

## Пользователи и вход

- Регистрация по приглашению — частично
- Вход на сайт по паролю — частично
- Роли admin / user — частично
- Подключение приложения по коду — частично
- Ротация refresh-токенов — реализовано
- Привязка Telegram — не реализовано
- Вход по passkey — отложено

## Список покупок

- Категории: создать, переименовать, удалить, переставить — частично
- Группы — частично
- Товары: добавить, изменить, удалить, переставить — частично
- Количество и отметка «в итоге» — частично
- Отмена удаления (3 секунды) — не реализовано
- «Куплено»: запись покупки, блок в категории — не реализовано
- Страница «Покупки» со статистикой — не реализовано
- Архив товаров — не реализовано
- Проверка цены 14 дней после покупки — не реализовано
- Конфликт версий при одновременной правке — не реализовано

## Цены и расчёты

- Лучшая цена с учётом карты и наличия — частично
- Итоги и изменение за сутки, неделю, месяц, год — частично
- Устаревание цены через 7 суток — частично
- Включение в итог товара с устаревшей ценой (с предупреждением) — частично
- Непрерывная история цены при замене и отключении ссылок — частично
- Графики цены по магазинам — частично
- График суммы категории и общего итога — частично
- Подозрительные изменения и решения — не реализовано

## Сбор цен

- Общий парсер с подтверждением администратора — не реализовано
- Адаптер DNS — не реализовано
- Адаптер Ozon — не реализовано
- Адаптер Wildberries — не реализовано
- Регион Санкт-Петербург — не реализовано
- Защита от SSRF — не реализовано
- Загрузка картинок на сервер — не реализовано
- Пауза домена и повтор при CAPTCHA — не реализовано

## Очередь и расписание

- Очередь заданий и worker — не реализовано
- Плановая проверка в 09:00, до трёх в сутки — не реализовано
- Ручной запуск администратором с прогрессом — не реализовано
- Срочная проверка при добавлении ссылки — не реализовано
- Общая цена для нескольких пользователей — не реализовано

## Уведомления и контроль

- Telegram-бот — не реализовано
- Сторож: worker, сервер, бот — не реализовано
- Сводка проверки пользователю в Telegram — не реализовано
- Колокольчик системных уведомлений администратора на сайте и в приложении — не реализовано
- Push через APNs — отложено

## Сайт

- Главная — не реализовано
- Категория — не реализовано
- Товар — не реализовано
- Группа — не реализовано
- Настройки пользователя — не реализовано
- Настройки администратора — не реализовано

## Приложение iPhone / iPad

- Вход и просмотр — не реализовано
- Отчёты об ошибках приложения на сервер — не реализовано
- Изменение количества и «в итоге» — не реализовано
- Настройки и редактирование товаров — отложено
- TestFlight — отложено

## Эксплуатация

- Деплой на Raspberry Pi, туннель без расшифровки через арендный хост — не реализовано
- Копии на домашний узел и арендный хост, 30 суток — не реализовано
- Копии на NAS — не реализовано (после реализации выключено флагом)
- Staging, метрики, серверный кэш — отложено

# Статус функционала

Обновляется после каждой задачи. Одна строка на функцию. Статусы: реализовано / частично / не реализовано / отложено.

## Основа

- Карта проекта и проверка границ модулей — реализовано
- Конфигурация, логи, типизированные ошибки — реализовано
- Схема базы и миграции — частично
- Запуск на macOS, Windows и Linux — реализовано

## Пользователи и вход

- Регистрация по приглашению — реализовано
- Вход на сайт по паролю — реализовано
- Роли admin / user — реализовано
- Повышение пользователя до администратора — отложено
- Удаление данных заблокированного пользователя через 7 суток — реализовано
- Окончательная очистка удалённого через 30 дней — реализовано
- Подключение приложения по коду — реализовано
- Смена пароля — реализовано
- Ротация refresh-токенов — реализовано
- Привязка Telegram — реализовано
- Вход по passkey — отложено

## Список покупок

- Категории: создать, переименовать, удалить, переставить — реализовано
- Группы — реализовано
- Товары: добавить, изменить, удалить, переставить — реализовано
- Количество и отметка «в итоге» — реализовано
- Отмена удаления (3 секунды) — реализовано
- «Куплено»: запись покупки, блок в категории — реализовано
- Страница «Покупки» со статистикой — реализовано
- Архив товаров — реализовано
- Проверка цены 14 дней после покупки — реализовано
- Конфликт версий при одновременной правке — частично

## Цены и расчёты

- Лучшая цена с учётом карты и наличия — частично
- Итоги и изменение за сутки, неделю, месяц, год — частично
- Устаревание цены через 7 суток — частично
- Включение в итог товара с устаревшей ценой (с предупреждением) — реализовано
- Непрерывная история цены при замене и отключении ссылок — частично
- Графики цены по магазинам — частично
- График суммы категории и общего итога — частично
- Подозрительные изменения и решения — реализовано

- Магазин создаётся сам при добавлении ссылки с нового сайта, без подтверждения администратора — частично

- Адаптер Яндекс Маркет — реализовано

- Процесс worker: цикл заданий, паузы магазинов, продление аренды — реализовано
- Плановая проверка в 09:00, до трёх в сутки — реализовано
- Пропущенная плановая проверка после старта сервера — реализовано
- Ручной запуск администратором с прогрессом — реализовано
- Остановка запуска администратором — реализовано
- Возврат задания при обрыве worker, до трёх попыток — реализовано
